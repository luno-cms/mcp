# Security

Report vulnerabilities in **this MCP client** via [GitHub Security Advisories](https://github.com/luno-cms/mcp/security/advisories) on `luno-cms/mcp`.

Do **not** use this repo to report:

- Hosted LUNO SaaS issues (auth, billing, data isolation, production incidents)
- Leaked customer agent keys (revoke in Console immediately)

We do not accept secrets in issues or pull requests.
